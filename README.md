# VerifEye（网页可信度实时评估 Chrome 插件）

> 一款 Chrome 浏览器扩展：浏览时在右下角以红/黄/绿三色与 0–100 分实时评估网页可信度，检测钓鱼链接、验证内容真实性，并分析信息来源权威性。

## 核心方法/技术/功能

- **悬浮窗评分**：右下角悬浮窗用红、黄、绿三色与 0–100 分直观展示当前网页可信度。
- **风险检测**：识别钓鱼链接，标记未经验证的信息。
- **来源分析**：抓取网页内容、比对全网信息，综合计算可信度得分。
- **详细报告**：点击悬浮窗可查看详细报告，列出风险链接与未验证信息。
- **轻量不打扰**：后台运行，不干扰正常浏览。

- 加载方式：解压 `VerifEye-v1.zip`，在 Chrome「扩展程序 → 开启开发者模式 → 加载已解压的扩展程序」中载入（具体以压缩包内 `manifest.json` 为准）。
